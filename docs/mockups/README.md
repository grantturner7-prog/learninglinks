# LearningLinks mock-ups (design review, updated 17 Nov 2026)

Clickable design canvas (private link, shared by the owner): https://claude.ai/artifact/8xznCyo9qLUWY9cL6cjPSy

Twelve boards, each with an EN / 繁中 switch. Sample data only.

1. Home
2. Find educators (switch between visitor, school member and family member views)
3. Educator profile, school view
4. Educator sign-up: waiver (with the required acknowledgement)
5. Educator profile builder ("open to" decides who can see you)
6. School dashboard
7. School membership and checkout (NT$10,000 first campus + NT$5,000 per extra campus, VAT included)
8. Families landing page
9. Phone: home
10. Phone: shared profile link (visitor wall)
11. Family membership and checkout (NT$2,000, VAT included)
12. Tutor profile, family view

Rules the boards demonstrate: nobody sees any educator without a paid membership; families see only
educators who offer private tutoring; schools see only educators open to full-time or part-time work;
there is no live matching and no substitute work; the compliance notice appears on every board.

`source/` holds the board files for the record. They need the design canvas runtime to render, so
open the link above rather than the files.
