Before you book a first lesson預約第一堂課之前

Please read:請注意： We only connect people. We do not run background checks on anyone. Please complete all checks and follow all government policies and procedures yourself.我們僅提供連結服務，不對任何人進行背景調查。請自行完成所有查核，並遵守所有政府政策與程序。
  • Confirm identity and ask for ID.確認身分並請對方出示證件。
  • Ask for a police record certificate yourself. We never see it.自行索取良民證，我們不會取得。
  • Start in a public place, or online with a parent present.先在公共場所，或由家長在場的線上開始。
  • Check the tutor may legally tutor.確認對方可合法從事家教。
